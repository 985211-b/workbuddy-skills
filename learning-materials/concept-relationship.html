概念关系

本页梳理 WorkBuddy 生态中几个核心概念之间的联系，帮助理解 Agent、Skill、LLM Context、Memory 与 Tools 如何协同工作。

Agent ↔ Skill

Agent 是执行任务的智能体，Skill 是 Agent 可调用的能力模块。多个 Skill 可以被加载到一个会话中，根据用户输入触发。

Agent ↔ LLM Context

Agent 将 Skill 说明、记忆、工具结果等注入 LLM Context，让模型在每次推理时拥有完成任务所需的全部信息。

Skill ↔ Memory

Skill 可以读取 Memory 中的用户偏好与长期事实，从而提供更加个性化的服务；Skill 的执行结果也可写回 Memory。

Agent ↔ Tools / MCP

Agent 通过 Tools（包括 MCP 工具）与外部世界交互，例如读写文件、调用 API、发送邮件、操作浏览器等。
