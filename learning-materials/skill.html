Skill 智能体技能

给 Agent 的"入职手册"——把经验写成文件，谁来都能照着干

① 是什么② 三层加载③ 与相邻概念④ 真实案例⑤ 常见误区⑥ 记住这几点
Skill = 把"怎么做某类事"的完整知识打包成一个文件夹（最小只需一个 SKILL.md），让 Agent 按需加载、自动复用。
Anthropic 的类比：给新员工写入职手册——不需要定制一个"专门的人"，把老员工的经验写成手册就行。

1灵魂设计：三层按需加载

渐进式披露（Progressive Disclosure）——本质是对上下文窗口的精细管理：

为什么关键：如果没有分层，挂 50 个完整技能会同时打爆三个瓶颈——窗口溢出、注意力稀释（选错技能/填错参数）、每轮重复输入数万 token（成本失控）。分层设计把三座山全部搬走。

运行三步：发现 → 触发 → 执行（点开看）

发现：启动时只扫描元数据，生成轻量"技能目录"。触发：请求匹配某个 description 时，读取完整 SKILL.md——只有这一份进上下文。执行：脚本直接跑代码拿结果（代码不进上下文），任务结束后厚重内容可移除。

2与相邻概念的分界

💡 一句话记住：Tool 是手，MCP 是外部接口，Skill 是打法手册

生产级 Agent 三者全用：系统提示定基线行为，MCP 连外部数据，Skill 沉淀"怎么用好"的组织经验。

时间线：Anthropic 2025 年 10 月推出 Agent Skills，12 月发布为开放标准（agentskills.io，捐给 Linux 基金会旗下 AAIF）。48 小时内 Microsoft 和 OpenAI 跟进，2026 年 3 月已有 32 个工具采用 SKILL.md 格式——写一次，处处能跑。

3真实案例

场景：Uber 的 Skill 生态，从 2 个长到 500+。

怎么长起来的
阶段发生了什么
起点2025.10 一位平台工程师深夜自建内部市场，只放 2 个 Skill（CI 日志分类、代码评审修复）
拐点2026.1 工程团队集体"aha 时刻"，像多米诺一样扩散
现状精选市场 200+，全市场合计 500+，一周新增 20 个，零管理层推动

治理是关键：黄金市场入库须过三道关（人工代码评审、CI/CD、LLM 自动评估），刻意控制在约 100 个核心 Skill；个人/团队市场自由实验，验证有效后"毕业"。每个 Skill 有明确 Owner。

效果：覆盖整个开发生命周期，增长完全自驱。浓缩成一句：最好的 Skill 往往来自某个工程师深夜的发现，而不是中心化决策——但前提是质量闸门守好。

4常见误区

❌ Skill 就是保存的 Prompt

差三个量级。Prompt 是一段话，用完即弃；Skill 是文件夹：指令 + 示例 + 脚本，可 Git 管理、团队共享、跨平台移植。判断标准：一段话能说清的用系统提示；需要检查清单和脚本的，做成 Skill。

❌ 装得越多越强

恰恰相反。description 写弱了会漏触发，重复冲突会让 Agent 选择困难。Uber 把黄金市场刻意控制在约 100 个。

❌ Skill 是确定性的

不是，它由 LLM 解释执行。需要可靠的环节，把关键部分做成 Skill 里捆绑的脚本——指令管灵活，代码管可靠。

❌ 装第三方 Skill 很安全

Skill 可含可执行代码，等于给 Agent 装第三方代码，必须走安全审查。这是企业部署失败率高的头号原因。

5记住这几点

✅ 记忆锚点

  • 定位：Skill 是"打法手册"，Tool 是"手"，MCP 是"接口"
  • 架构：三层渐进披露，L1 常驻最便宜，L3 脚本不进上下文
  • 维护：每个 Skill 有 2~4 小时/月的维护成本，没 Owner 的市场会变"数字废墟"
  • 双刃剑：好经验规模化多快，坏经验规模化就多快——复用前先确认流程是对的

7五道测试题（点开看答案）

① Skill 三层加载中，常驻最便宜的是？

✅ L1 元数据（name + description，约 50~100 tokens），L2 按需才读，L3 脚本代码根本不进上下文

② Skill 与系统提示的关键区别是？

✅ Skill 是按需加载的文件包，可分享、版本管理、跨平台；系统提示是常驻的一段文字

③ 哪种内容不适合做成 Skill？

✅ 每次都不同的临时任务（适合做成 Skill 的：检查清单、可复用流程、领域知识、配套脚本）

④ Skill 自动触发主要依赖哪个字段？

✅ description——它描述"什么场景下用我"，写得越准，触发越稳

⑤ Skill 装得越多越好吗？

✅ 不是。description 弱会漏触发，过多会注意力稀释、选择困难。Uber 黄金市场刻意控制在约 100 个
