Skill 简介

Skill 是 WorkBuddy 中可复用的能力单元。每个 Skill 定义了一组触发条件、可执行能力和使用说明，帮助 Agent 在特定场景下表现得更专业、更稳定。

标准结构

.workbuddy/skills/<skill-name>/SKILL.md

SKILL.md 核心内容

  • 概述：Skill 解决什么问题
  • 触发条件：用户说什么时会激活该 Skill
  • 能力范围：它能做什么、不能做什么
  • 使用方式：如何调用、参数说明
  • 示例：典型对话示例

命名建议

  • 使用英文小写，单词间用连字符 - 分隔
  • 名称应体现场景，例如 repo-bootstrap、doc-reviewer
