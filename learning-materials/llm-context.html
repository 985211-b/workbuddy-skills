LLM Context 简介

LLM Context（上下文）是模型在每次推理时可见的全部信息集合。合理管理上下文能显著提升 Agent 的回答质量与任务完成度。

上下文组成

  • 系统提示（System Prompt）：定义模型角色、规则与输出格式
  • 用户消息（User Message）：当前任务或问题
  • 历史对话：多轮交互记录
  • 外部注入信息：文件内容、工具返回结果、记忆片段等

上下文管理技巧

  • 只保留与当前任务最相关的历史，避免信息过载
  • 长文档采用「分块 + 摘要」策略
  • 把结构化信息（如 JSON）放在用户消息末尾
  • 为工具调用结果添加明确的角色标签，便于模型理解
